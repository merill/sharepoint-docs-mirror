# Edit the Resources web part - SharePoint in Microsoft 365 | Microsoft Learn

The Resources web part enables organizations to display a centrally managed set of links across SharePoint pages of a SharePoint home site, allowing consistent reuse of links within a site. Unlike page-specific link collections, the Resources web part references content stored separately from the page, so updates are reflected consistently everywhere the web part is used.

Resources provide links to the most popular portals and destinations at your organization. This web part can be used within a SharePoint home site, often used within the [SharePoint app in Teams](sharepoint-app-in-teams-overview). Operators and members can import navigational links from a SharePoint home site or global navigation bar, or create their own links, which can all be [targeted to specific audiences](use-audience-targeting-sharepoint-app-in-teams). Any edits made to the Resource section will also show in the mobile experience.

Note

- Global navigation can be accessed by clicking on the **SharePoint** icon in the Teams app bar. [Refer to this document if you're setting up global navigation for the first time.](sharepoint-app-bar)

## Add a resource link

1. Navigate to the Resources web part within your SharePoint home site and select **Edit**.
2. To add a new link, select **+ Add Link**.
3. In the Add a Link window that opens, paste the link to the site in the **URL** field.

    - Only modern SharePoint sites and certain Microsoft 365 experiences that you link to display in Teams. All other types of content open in a separate browser window.
4. Enter a **Display name**.
5. Under Thumbnail, select a choice to represent your resource link.

    - **Auto-selected**: the icon is generated based on the URL, if applicable (a link icon displays by default if one can't be autogenerated).
    - **Custom**: upload your own image as an icon by selecting **Change** and uploading your image (the image will resize to fit the icon's dimensions).
    - **Icon**: choose an icon from a preexisting list by selecting **edit icon**.
6. To apply audience targeting to this resource, enter one or more Microsoft 365 Groups in the **Audiences to target** field (up to 10 audiences can be targeted). Learn more about [audience targeting for resources](use-audience-targeting-sharepoint-app-in-teams).
7. Select **Save**.

    ![Screenshot showing the 'add a link' properties.](../sharepointonline/media/homesites/edit-viva-home/atr-audiences-to-target.png)
8. The new resource appears. If audience targeting is active, you’ll see an icon in the upper left of the resource link.

    ![Screenshot of the audience targeting icon shown in the upper left of the resource link.](../sharepointonline/media/homesites/edit-viva-home/atr-audience-targeting-icon.png)
9. Continue editing your resource links. When finished, select **Save** to confirm your changes.

## Import SharePoint links

You can import navigational links from a SharePoint home site and the SharePoint global navigation bar into your resources.

1. Start by selecting **Edit** in the Resources web part.
2. Select **Import SharePoint links**.
3. Select which navigation you want to **import from** (unavailable navigation is greyed out).
4. Select which links to import.
5. Select **Keep audience targeting** if you want to enable existing audience targeting settings for your selected imported links.
6. Select **Import**.

    ![Screenshot of the Import properties panel.](../sharepointonline/media/homesites/edit-viva-home/atr-import-sharepoint-links.png)
7. The selected links are added to your resources.
8. Continue editing your resource links. When finished, select **Save** to confirm your changes.

## Edit an existing resource link

1. Start by selecting **Edit** in the Resources web part.
2. Hover over the resource link and select the **ellipsis**.
3. Select **Edit** to open the resource link and change its settings.

    ![Screenshot of the resource link drop-down menu with the edit option highlighted.](../sharepointonline/media/homesites/edit-viva-home/atr-edit-resource.png)
4. When finished editing the resource link, select **Save** in the edit link window.
5. Continue editing your resource links. When finished, select **Save** to confirm your changes.

## Delete an existing resource link

1. Start by selecting **Edit** in the Resources web part.
2. Hover over the resource link and select the **ellipsis**.
3. Select **Delete**.

    ![Screenshot of the resource link drop-down menu with the delete option highlighted.](../sharepointonline/media/homesites/edit-viva-home/atr-delete-resource.png)
4. When asked to confirm, select **Delete**.
5. Continue editing your resource links. When finished, select **Save** to confirm your changes.

## Reorder existing resource links

1. Start by selecting **Edit** in the Resources web part.
2. Select a resource link and drag it to its new location.
3. Continue editing your resource links. When finished, select **Save** to confirm your changes.
