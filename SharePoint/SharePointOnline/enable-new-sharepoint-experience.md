# New SharePoint experience - SharePoint in Microsoft 365 | Microsoft Learn

SharePoint is redesigned for simplicity and clarity, centered on discovering, publishing, and building—now with flexible workflows and AI-first capabilities built in.

### What is in the new SharePoint experience?

The new SharePoint experience consists of the following changes:

1. The SharePoint home page is replaced with a *[Discover](https://support.microsoft.com/office/0b6cfbb0-5523-41d9-bc89-4f719f05fd51)* experience.
2. The SharePoint app bar is refreshed with a [newer experience](https://support.microsoft.com/office/e568387f-bfef-41cf-8dc0-e1fdc5c08c73).
3. The new app bar has two new destinations, *[Publish](https://support.microsoft.com/office/11d2b61d-7c25-4d7d-94cf-0abe66fb2936)* and *[Build](https://support.microsoft.com/office/cb17406a-59ea-488a-beb5-f8160af3ecb5)* destinations.
4. The new app bar will show global navigation at the top with the logo and name, if it is [enabled and configured in your Home site](/en-us/viva/connections/sharepoint-app-bar).
5. The visual updates include neutral app theming that applies a consistent, neutral palette to SharePoint UI surfaces and elevating content forward across key surfaces (including SPFx placeholders). Together, these changes reduce visual noise, improve readability, and bring clearer structure and visual focus to customer branding and content as users view and edit pages.
