# Search Center settings - SharePoint in Microsoft 365 | Microsoft Learn

As a [SharePoint Administrator](/en-us/sharepoint/sharepoint-admin-role) or [above](/en-us/microsoft-365/admin/add-users/about-admin-roles) in Microsoft 365, you specify where searches should go for your classic site collection or site by specifying the URL of your Search Center. For example, if you've created an Enterprise Search Center which users can use to search everything in your company, you must enter the URL of that site here.

## Enter the address of your Search Center

1. Go to [**More features** in the SharePoint admin center](https://go.microsoft.com/fwlink/?linkid=2185077), and sign in with an account that has [admin permissions](sharepoint-admin-role) for your organization.

Note

If you have Office 365 operated by 21Vianet (China), [sign in to the Microsoft 365 admin center](https://go.microsoft.com/fwlink/p/?linkid=850627), then browse to the SharePoint admin center and open the More features page.

1. Under **Search**, select **Open**.
2. On the **search administration** page, select **Search Center Settings**.
3. In the **Search Center URL** box, enter the URL of the Search Center site.

    Example: http://companyportal/searchcenter/pages.
4. Select **OK**.

Note

It may take up to 30 minutes before changes take effect.
